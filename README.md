# JEE Insights Pro

A responsive JEE Main Paper 1 preparation workspace with an interactive answer-and-review practice flow, official paper source catalogue, local progress tracking and automated screenshots.

## Current features
- Responsive dashboard with desktop/mobile navigation.
- Practice mode supporting single-correct MCQs and numerical answers.
- Submit-to-reveal feedback: correctness, answer, worked explanation and concept takeaway.
- Question navigator, mark-for-review, local attempt history and accuracy summary.
- PYQ source archive filters for years 2022–2026.
- Bookmarks saved in browser local storage.
- Provenance-aware question import validator and documented data schema.
- Playwright screenshot automation for desktop (1440 px) and mobile (390 px).
- GitHub Actions build and GitHub Pages deployment workflow.

## Run locally
```bash
npm install
npm run dev
```

## Verify and build
```bash
npm run typecheck
npm run build
```

## Question-bank status — read before relying on the app
The practice UI currently uses **four original demo questions**, visibly labelled **DEMO SET — NOT PYQs**. The verified official question dataset at `src/data/questions.json` is intentionally empty. The application does **not** yet contain all JEE Main PYQs from 2022–2026, and does not claim that it does.

NTA makes some paper and answer-key documents publicly available, but historical question/recorded-response material is spread across year/session-specific notices and candidate services. Each question must be matched to the correct final answer key and its metadata. Import only source-traceable records and reviewed solutions. See:
- [Official source catalogue](docs/QUESTION_SOURCE_CATALOGUE.md)
- [Question-bank schema and import process](docs/QUESTION_BANK_SCHEMA.md)
- [Data-source verification notes](docs/DATA_SOURCES.md)

The import validator:
```bash
node scripts/validate-question-import.mjs path/to/reviewed-questions.json
```

## Screenshots
Actual desktop/mobile browser screenshots are generated by the GitHub Actions workflow and committed to `docs/screenshots/` after a successful build. See [screenshot notes](docs/SCREENSHOTS.md).

## Deployment
The workflow builds the site and publishes `dist` to GitHub Pages. The repository's Pages configuration must be enabled with **Settings → Pages → Build and deployment → Source → GitHub Actions**. Expected URL: https://ver-dev9.github.io/JEE-Insights-Pro/

## Project structure
- `src/App.tsx` — dashboard, archive, practice flow and analytics.
- `src/data/demoQuestions.ts` — original demonstration questions, not PYQs.
- `src/data/questions.json` — official PYQ dataset placeholder.
- `src/data/papers.ts` — official paper/archive references.
- `scripts/validate-question-import.mjs` — import validation.
- `tests/screenshots.spec.ts` — desktop/mobile screenshot capture.
- `docs/` — architecture, source, schema, deployment and release notes.
