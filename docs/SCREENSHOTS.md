# Product screenshots

The GitHub Actions workflow captures actual browser screenshots at two viewport sizes after a successful production build:

- `docs/screenshots/desktop.png` — 1440 px desktop viewport
- `docs/screenshots/mobile.png` — 390 px mobile viewport
- `docs/screenshots/chapter-heatmap-empty-state.png` — verified-data empty state
- `docs/screenshots/question-explorer-empty-state.png` — question-bank empty state
- `docs/screenshots/study-planner-mobile.png` — mobile planner view

Screenshots are generated from the running built site using Playwright; they are not mockups. They are committed automatically by the workflow. If the Pages deployment workflow is not enabled in repository settings, the screenshots can still be generated by the build job before the deployment step.
